直接編集しない。設計の現行文書は `../../DESIGN_BRIEF.md`。

## `202610_Europe_TechEx_EuroBLECH/references/` との違い

EUROBLECH側は `rejected/` と `superseded/` の2つを使っている。
このフォルダはどちらとも役割が違うので、名前を分けている。

- `rejected/` = 一度採用を検討して**却下した**レイアウト試作
- `superseded/` = **現行の旅程と矛盾する**旧案。読むと事実を取り違える
- `design-samples/`（ここ） = 却下でも矛盾でもない。**採用案を含む比較資料**で、
  なぜ今の形になったかの経緯として参照する価値がある

ここのファイルは旅程の事実を含まないので、`superseded/` のような
「読むと事実を取り違える」危険はない。一方で**現行の仕様ではない**ため、
実装の基準にはしない。仕様を確認するときは `../../DESIGN_BRIEF.md` と
`../../index.html` を見る。
