#### `SEMICON_SEA_2026_共同調査ダッシュボード.html` ⭐【推奨】
- **形式**: HTML（ブラウザで開く）
- **内容**: 複数人での共同調査に対応した高機能版
- **特徴**:
  - ✅ **企業をクリックして詳細調査記録**
  - ✅ **訪問日時・訪問者名を記録**
  - ✅ **評価（S/A/B/C）を設定**
  - ✅ **訪問メモ・商談内容を入力**
  - ✅ **名刺・ブース写真をアップロード**（複数枚可）
  - ✅ **ブラウザに自動保存**（localStorage）
  - ✅ **JSONエクスポート/インポート**で他メンバーとデータ共有
  - ✅ 訪問済み企業でフィルター
  - ✅ 評価別フィルター
  - ✅ リアルタイム統計（訪問数、評価数）

**使い方**:

1. **基本操作**
   - ファイルをダブルクリックしてブラウザで開く
   - 企業の行をクリックすると詳細モーダルが開く

2. **調査記録の入力**
   - 訪問日時、訪問者名を入力
   - 評価（S/A/B/C）を選択
   - 訪問メモ・所感を記入
   - 商談状況を選択
   - 名刺や製品写真をアップロード（📷マークをクリック）
   - 「💾 保存」をクリック

3. **データ管理**
   - **自動保存**: 入力内容はブラウザに自動保存されます
   - **エクスポート**: 「📥 データエクスポート」で JSON ファイルをダウンロード
   - **インポート**: 「📤 データインポート」で他メンバーのデータを読み込み

4. **チームでの共有方法**
   ```
   ① 各メンバーが調査後、データをエクスポート
   ② SharePoint/OneDrive/BOX にアップロード
   ③ リーダーが全員のJSONファイルを順次インポート（マージ）
   ④ 統合されたデータを再度エクスポートして全員に配布
   ```

5. **フィルター機能**
   - ✅ 訪問済みのみ表示
   - 評価別表示（S/A/B/C）
   - 🌟 注目企業のみ表示
   - キーワード検索（訪問者名、コメントも検索可）

## 🎯 活用シーン

### 🤝 チーム共同調査ワークフロー（推奨）

#### **準備段階（展示会前）**

1. **リーダーが初期セットアップ**
   - `SEMICON_SEA_2026_共同調査ダッシュボード.html` を SharePoint/OneDrive にアップロード
   - チームメンバー全員にアクセス権限を付与
   - 各自ダウンロードしてローカルで使用

2. **担当エリア・企業の割り当て**
   - **アルファベット別リスト**または**ブースエリア別リスト**で分担
   - 各メンバーに担当ファイルを配布

#### **展示会当日（現地調査）**

**パターンA: オフライン調査（推奨）**
```
各メンバー：
1. 共同調査ダッシュボードをスマホ/タブレットで開く
2. 企業を訪問したら、その場でクリックして記録
   - 訪問日時（自動入力推奨）
   - 訪問者名（自分の名前）
   - 評価（S/A/B/C）
   - メモ・所感
   - 名刺をスマホで撮影→その場でアップロード
   - ブース写真も撮影→アップロード
3. データは自動的にブラウザに保存される
```

**パターンB: エリア効率訪問**
```
午前: エリア1000を田中さん・鈴木さんで分担
午後: エリア2000を佐藤さん・高橋さんで分担
```

#### **展示会後（データ統合）**

**ステップ1: 各自がデータをエクスポート**
```
1. 共同調査ダッシュボードで「📥 データエクスポート」をクリック
2. JSONファイルがダウンロードされる
   ファイル名例: SEMICON_SEA_2026_調査データ_2026-05-07.json
3. SharePoint/OneDrive/BOX の共有フォルダにアップロード
   フォルダ構成例:
   /SEMICON_SEA_2026/調査データ/
   ├── 村上_2026-05-07.json
   ├── 田中_2026-05-07.json
   ├── 鈴木_2026-05-07.json
   └── 佐藤_2026-05-07.json
```

**ステップ2: リーダーがデータを統合**
```
1. 新しいブラウザで共同調査ダッシュボードを開く
2. 「📤 データインポート」で各メンバーのJSONを順次読み込み
   ※ インポート時に「キャンセル」を選ぶとマージされる
3. 全員分をインポート後、「📥 データエクスポート」
4. 統合データを共有フォルダにアップロード
   ファイル名例: SEMICON_SEA_2026_統合データ_2026-05-08.json
```

**ステップ3: 統合データを全員で確認**
```
1. 統合データをダウンロード
2. 共同調査ダッシュボードで「📤 データインポート」
3. 全チームの調査結果を閲覧
4. 評価フィルターで優先企業を抽出
   - 評価Sのみ表示 → 最優先フォローリスト
   - 訪問済みのみ表示 → 訪問実績レポート
```

#### **画像データの扱い**

## 🔧 トラブルシューティング（共同調査ダッシュボード）

### Q1: データが保存されない
**A:** ブラウザのlocalStorageを使用しています。
- プライベートブラウジング（シークレットモード）では保存されません
- 通常モードで開いてください
- ブラウザのキャッシュクリアで消える可能性があるため、定期的にエクスポートを推奨

### Q2: 画像をアップロードできない
**A:** ブラウザの制約があります。
- 画像サイズ: 1枚あたり2MB以下推奨
- 合計容量: localStorage上限（約5-10MB）に注意
- 大量の画像は BOX 別管理を推奨

### Q3: インポートで上書きされた
**A:** インポート時の選択を確認してください。
- 「OK」→ 完全上書き
- 「キャンセル」→ マージ（既存データ保持して追加）
- 事前にエクスポートでバックアップを推奨

### Q4: スマホで使えない
**A:** ブラウザで開けば使用可能です。
- Safari（iOS）、Chrome（Android）推奨
- ファイルをOneDriveやBOXにアップロードしてアクセス
- または自分宛にメールで送信してスマホで開く

### Q5: 他のメンバーのデータと統合したい
**A:** インポート機能を使用してください。
1. 全員がエクスポート（JSON）
2. リーダーが順次インポート（キャンセルでマージ）
3. 統合データをエクスポートして配布

### Q6: Excelで管理したい
**A:** 以下の方法があります。
1. 共同調査ダッシュボードで調査
2. エクスポートしたJSONをExcel変換ツールで変換
3. または `SEMICON_SEA_2026_全出展企業リスト.xlsx` に手動でコピー

### Q7: データのバックアップは？
**A:** 定期的なエクスポートを強く推奨します。
- 毎日の調査終了時にエクスポート
- SharePoint/OneDrive/BOXに保存
- 日付入りファイル名で管理
  例: `調査データ_2026-05-05.json`
