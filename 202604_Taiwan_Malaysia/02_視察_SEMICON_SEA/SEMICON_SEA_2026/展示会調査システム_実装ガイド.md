## システム概要

### 目的
展示会（国際・国内）での現場調査を効率化し、複数人でリアルタイムに情報共有できるシステムを構築する。

### 主な機能
- ✅ スマホで企業検索・訪問記録入力（30秒で完了）
- ✅ 写真・コメント・評価を即座に保存
- ✅ 複数人が同じ企業に別々の記録を追加可能
- ✅ 訪問者・日時の自動記録
- ✅ リアルタイム同期（全員が最新情報を閲覧）
- ✅ 事後分析用データエクスポート

### 利用シーン

#### 国際展示会（例: SEMICON Southeast Asia 2026）
```
【事前準備】
605社の出展企業リストを準備
優先度を設定（S/A/B/C）

【現場】
スマホで企業を検索 → 訪問記録を追加
写真撮影・コメント入力 → 保存

【事後】
全訪問記録をエクスポート → 報告書作成
```

#### 国内展示会（例: CEATEC）
```
【事前準備】
空のリストでスタート

【現場（クローラー型）】
気になるブースを発見 → その場で新規登録
企業名・写真・コメント → 保存

【事後】
訪問企業リストを整理 → フォローアップ
```

## 要件と制約

### 利用可能な環境
- ✅ **Microsoft 365**（Teams, SharePoint, Lists）
- ✅ **BOX**（ファイル共有）
- ❌ 一般クラウドサービス（使用不可）

### 必須要件
1. **スマホ完結**: 社有スマホで現場入力可能
2. **複数人対応**: 同じ企業に複数人が記録を追加できる
3. **写真管理**: 名刺・ブース・製品写真を保存
4. **自動化**: 訪問者名・日時は自動記録
5. **簡単操作**: 面倒な手順は避ける（5ステップ以内）

## システム構成

### アーキテクチャ

```
Microsoft Teams チーム
├── タブ①: 企業マスタ（Lists）
│   └── 605社の企業情報（事前登録）
│
├── タブ②: 訪問記録（Lists）
│   └── 現場での訪問記録（複数人が追加）
│
└── ファイル
    └── 写真フォルダ（自動整理）
```

### データ構造

#### リスト①: 企業マスタ

| 列名 | タイプ | 説明 | 例 |
|------|--------|------|-----|
| ID | 数値（自動） | 企業ID | 1 |
| 企業名 | 1行テキスト | 必須 | DAIFUKU CO, LTD. |
| ブース番号 | 1行テキスト | 検索用 | A101 |
| 事前優先度 | 選択肢 | S/A/B/C/未設定 | S |
| 概要 | 複数行テキスト | 事前調査内容 | 物流自動化のリーダー... |
| 注目企業 | Yes/No | ⭐マーク用 | Yes |

#### リスト②: 訪問記録

| 列名 | タイプ | 説明 | 自動/手動 |
|------|--------|------|-----------|
| ID | 数値（自動） | 記録ID | 1 |
| **企業** | **ルックアップ** | 企業マスタと連携 | 手動選択 |
| 評価 | 選択肢 | S/A/B/C/未評価 | 手動 |
| コメント | 複数行テキスト | 技術内容・商談メモ | 手動 |
| 商談状況 | 選択肢 | 要フォロー/商談予定/見積依頼/対象外 | 手動 |
| 写真 | 添付ファイル | ブース・名刺・製品 | 手動 |
| **作成者** | 人またはグループ | 訪問者 | **自動** |
| **作成日時** | 日付と時刻 | 訪問日時 | **自動** |
| 更新者 | 人またはグループ | 最終編集者 | **自動** |
| 更新日時 | 日付と時刻 | 最終更新日時 | **自動** |

### ルックアップ設定の効果

```
訪問記録リストで「企業」列に「DAIFUKU」を選択
↓
自動的に表示される情報:
├── ブース番号: A101
├── 事前優先度: S
└── 概要: 物流自動化のリーダー...
```

## 実装手順

### Phase 1: Teams チーム作成（5分）

#### 手順
1. **Teams アプリを開く**
2. **左メニュー「チーム」をクリック**
3. **「チームに参加、またはチームを作成」**
4. **「チームを作成」**
   - チーム名: `SEMICON 2026調査`
   - プライバシー: `プライベート`
   - メンバー追加: 調査参加者全員
5. **完了**

---

### Phase 2: Lists 作成（20分）

#### ステップ 2-1: 企業マスタリスト作成

1. **Teams で作成したチームを開く**
2. **上部の「+」タブ追加ボタンをクリック**
3. **「Lists」を選択**
4. **「新しいリスト」を作成**
   - リスト名: `企業マスタ`
   - 説明: `出展企業の基本情報`
5. **列を追加**（右上「+列の追加」）

| 追加順 | 列名 | 列の種類 | 設定 |
|--------|------|----------|------|
| 1 | 企業名 | 1行テキスト | 必須 |
| 2 | ブース番号 | 1行テキスト | |
| 3 | 事前優先度 | 選択肢 | S, A, B, C, 未設定 |
| 4 | 概要 | 複数行テキスト | リッチテキスト |
| 5 | 注目企業 | Yes/No | デフォルト: No |

#### ステップ 2-2: 訪問記録リスト作成

1. **再度「+」タブ追加 → Lists → 新しいリスト**
   - リスト名: `訪問記録`
   - 説明: `現場での訪問記録（複数人が追加可能）`

2. **列を追加**

| 追加順 | 列名 | 列の種類 | 設定 |
|--------|------|----------|------|
| 1 | **企業** | **ルックアップ** | ソース: 企業マスタ<br>表示列: 企業名<br>追加列を表示: ブース番号, 事前優先度 |
| 2 | 評価 | 選択肢 | S, A, B, C, 未評価 |
| 3 | コメント | 複数行テキスト | リッチテキスト |
| 4 | 商談状況 | 選択肢 | 要フォロー, 商談予定, 見積依頼, 対象外, 未定 |
| 5 | 写真 | 添付ファイル | |

> **💡 ルックアップ設定のポイント:**
> - 「このリストから情報を取得」→ 企業マスタ
> - 「表示する列」→ 企業名
> - 「追加列を表示」→ ブース番号, 事前優先度 にチェック

3. **作成者・作成日時は自動的に記録される**（設定不要）

---

### Phase 3: データ投入（10分）

#### 既存データの準備

現在のSEMICON_SEA_2026フォルダのデータをExcel形式に変換します。

**ファイル構成:**
```
SEMICON_SEA_2026/
├── SEMICON_SEA_2026_全出展企業リスト.xlsx （既存）
├── 出展社リスト_詳細版.md （既存）
└── 企業マスタ_インポート用.xlsx （新規作成）
```

#### Excel変換手順

既存のHTMLダッシュボードまたはExcelファイルから、以下の形式でデータを準備:

| 企業名 | ブース番号 | 事前優先度 | 概要 | 注目企業 |
|--------|-----------|-----------|------|----------|
| DAIFUKU CO, LTD. | A101 | S | 物流自動化のリーダー... | TRUE |
| Yamaha Robotics | B202 | S | 産業用ロボット... | TRUE |
| ... | ... | ... | ... | ... |

#### Lists へインポート

1. **企業マスタリストを開く**
2. **上部メニュー「統合」→「Excel から」**
3. **準備したExcelファイルを選択**
4. **列マッピングを確認**
5. **インポート実行**

---

### Phase 4: ビュー設定（10分）

#### 企業マスタのビュー

##### ビュー1: 全企業（デフォルト）
- 表示: すべての企業
- ソート: 企業名（昇順）

##### ビュー2: 注目企業のみ
- フィルター: 注目企業 = Yes
- ソート: 事前優先度（S→A→B→C）

##### ビュー3: 優先度S
- フィルター: 事前優先度 = S
- ソート: ブース番号

#### 訪問記録のビュー

##### ビュー1: 全記録（デフォルト）
- 表示: すべての訪問記録
- ソート: 作成日時（新しい順）
- グループ化: 企業（同じ企業の記録がまとまる）

##### ビュー2: 未訪問企業
- 企業マスタと訪問記録を比較して、訪問記録がない企業を表示
  （※Lists標準機能では難しい → Power Automate で別途集計）

##### ビュー3: 自分の訪問記録
- フィルター: 作成者 = [自分]
- ソート: 作成日時（新しい順）

##### ビュー4: 評価S のみ
- フィルター: 評価 = S
- ソート: 作成日時（新しい順）

#### 条件付き書式設定

**訪問記録リスト:**

1. **リストの設定 → 書式設定 → 行の書式設定**
2. **条件を追加:**

```json
{
  "elmType": "div",
  "style": {
    "background-color": "=if([$Rating] == 'S', '#fff9c4', if([$Rating] == 'A', '#c8e6c9', if([$Rating] == 'B', '#bbdefb', '')))"
  }
}
```

これにより:
- 評価S → 金色の背景
- 評価A → 緑色の背景
- 評価B → 青色の背景

## 使い方マニュアル

### 📱 スマホでの操作（現場）

#### ケース1: 事前リストにある企業を訪問

```
【画面の流れ】

1. Teams アプリを開く
   ↓
2. チーム「SEMICON 2026調査」をタップ
   ↓
3. タブ「訪問記録」をタップ
   ↓
4. 検索バーで企業名またはブース番号を入力
   例: 「DAIFUKU」または「A101」
   ↓
5. （既存の訪問記録があれば表示される）
   例: 村上さんが5/5 10:00に訪問済み
   ↓
6. 右下の「+」ボタンをタップ
   ↓
7. フォームが表示される
   ├── 企業: ドロップダウンから「DAIFUKU」を選択
   │   └→ ブース番号「A101」が自動表示
   ├── 評価: タップして「S」を選択
   ├── コメント: 「AGV新製品確認。技術担当の山田氏と商談予定」
   ├── 商談状況: 「商談予定」を選択
   └── 📎 添付ファイル: 「写真を追加」
       └→ カメラ起動 → 撮影（複数枚可）
   ↓
8. 右上の「保存」をタップ
   ↓
9. 自動的に記録
   - 作成者: 田中太郎（ログインユーザー）
   - 作成日時: 2026/5/5 14:30
   ↓
10. 完了！（全員が即座に閲覧可能）
```

**所要時間: 約30秒**

#### ケース2: 事前リストにない企業を発見（国内展示会）

```
【画面の流れ】

1. Teams → 「訪問記録」タブ
   ↓
2. 「+」ボタン → 新規作成
   ↓
3. フォーム入力
   ├── 企業: 「新規企業」として手入力
   │   または、企業マスタに先に追加
   ├── 評価: A
   ├── コメント: 「IoTセンサー展示。カタログ入手」
   └── 写真: ブース写真・名刺を撮影
   ↓
4. 保存
```

## よくある質問

### Q1: 同じ企業に2人が同時に記録するとどうなる?

**A:** 大丈夫です。それぞれ別の記録として保存されます。

```
【例】
5/5 10:00 - 村上が DAIFUKU を訪問
├── 評価: S
└── コメント: AGV確認

5/5 14:00 - 田中が DAIFUKU を訪問
├── 評価: A
└── コメント: 担当者と商談

結果: 2件の記録が残る
企業マスタで DAIFUKU をタップ
→ 訪問記録2件が表示される
```

---

### Q2: 写真はExcelエクスポートに含まれる?

**A:** 写真ファイル名はエクスポートされますが、画像本体は別途ダウンロードが必要です。

**写真の取得方法:**
```
1. SharePoint サイトを開く
   URL: https://yourcompany.sharepoint.com/sites/...
   ↓
2. Lists → 訪問記録 → Attachments フォルダ
   ↓
3. 各記録IDごとにフォルダがある
   例: /Attachments/1/ → 村上さんの写真
       /Attachments/2/ → 田中さんの写真
   ↓
4. フォルダごとダウンロード
```

**自動化オプション:**
Power Automate で写真を OneDrive/BOX に自動バックアップ可能

---

### Q3: オフラインでも使える?

**A:** 部分的に可能です。

```
✅ 可能:
- Lists の閲覧（キャッシュがあれば）
- 下書き保存（Teams モバイルアプリ）

❌ 不可:
- 新規記録の保存（ネット接続必須）
- 写真のアップロード
```

**推奨:**
展示会場のWi-Fiまたは携帯回線を使用

## サポート情報

### 問題が発生した場合

1. **Lists が表示されない**
   → Teams タブの「その他」から探す

2. **ルックアップが設定できない**
   → 企業マスタリストが先に存在するか確認

3. **写真がアップロードできない**
   → ファイルサイズを確認（1枚10MB以下推奨）

4. **データが同期されない**
   → ブラウザをリフレッシュ（F5）

## まとめ

このシステムの特徴:

✅ **シンプル**: Lists だけで実現、複雑な開発不要  
✅ **高速**: スマホで30秒で記録完了  
✅ **確実**: 複数人の記録がすべて残る  
✅ **自動**: 訪問者・日時は自動記録
