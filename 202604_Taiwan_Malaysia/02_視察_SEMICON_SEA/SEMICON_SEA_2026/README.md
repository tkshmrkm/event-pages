## 🎯 活用シーン

### 展示会前の準備

**1. 事前調査・ターゲット企業選定**
- **ダッシュボード**で「ロボット」「モーション」「センサー」などのキーワード検索
- **Excelリスト**で注目企業（🌟）をフィルター
- **詳細調査レポート**で技術詳細を確認

**2. チーム分担の計画**
- **アルファベット別リスト**で担当範囲を分割
  - 例：田中さん→A-G、鈴木さん→H-N、佐藤さん→O-Z
- 各メンバーに対応するExcelファイルを配布

**3. 効率的な動線設計**
- **ブースエリア別リスト**で会場の回り方を計画
  - 例：午前中はエリア1000、午後はエリア2000とA
- エリアごとの優先企業をマーク

### 展示会当日

**パターン1: エリア別効率訪問**
1. **ブースエリア_エリア 1000.xlsx**を開く
2. ブース番号順に並んでいるので、順番に回る
3. 次のエリアに移動したらファイルを切り替え

**パターン2: リアルタイム検索**
- **ダッシュボード**をスマホで開いて、その場で企業情報を確認
- ブース番号で素早く検索
- 興味のある技術キーワードで関連企業を発見

**パターン3: アルファベット担当制**
- 各担当者が自分の**アルファベット別リスト**を持参
- 担当範囲の企業を効率的に訪問

### 展示会後のフォローアップ

**1. 訪問記録の整理**
- **Excelリスト**で名刺交換企業にマーク・メモ追加
- エリア別・アルファベット別に分けて報告書作成

**2. 技術評価・優先順位付け**
- **詳細調査レポート**で技術的評価
- 商談候補企業の優先順位付け

**3. チーム情報共有**
- 各担当者のアルファベット別/エリア別レポートを統合
- 全体像の把握と次のアクション決定
