## 🎯 システム概要（まとめ）

### 解決した課題

❌ **以前の問題:**
- HTMLダッシュボードは単独使用のみ（複数人で共有できない）
- 写真やコメントを追加する手段がない
- SharePoint REST APIの権限問題
- リアルタイム同期が不可能

✅ **新システムで実現:**
- Microsoft Lists で複数人がリアルタイム共有
- スマホから30秒で訪問記録・写真・コメント入力
- 同じ企業に複数人が別々の記録を追加可能
- 訪問者・日時は自動記録
- 権限不要、M365だけで実現

## 🏗️ システム構成

### アーキテクチャ

```
Microsoft Teams チーム「SEMICON 2026調査」
├── タブ①: 企業マスタ（Lists）
│   ├── 605社のデ ータ（事前登録）
│   └── 企業名、ブース、優先度、概要

## 📱 使い方（クイックガイド）

### スマホでの記録（30秒）

```

## 🚀 実装手順（40分）

### Phase 1: Teams チーム作成（5分）

1. Teams で新しいチーム作成
2. チーム名: `SEMICON 2026調査`
3. メンバー追加

### Phase 2: Lists 作成（20分）

#### リスト①: 企業マスタ

```
タブ追加 → Lists → 新しいリスト
リスト名: 企業マスタ

列を追加:
├── 企業名（1行テキスト、必須）
├── ブース番号（1行テキスト）
├── 事前優先度（選択肢: S/A/B/C/未設定）
├── 概要（複数行テキスト）
└── 注目企業（Yes/No）
```

#### リスト②: 訪問記録

```
タブ追加 → Lists → 新しいリスト
リスト名: 訪問記録

列を追加:
├── 企業（ルックアップ ← 企業マスタ）⭐重要
├── 評価（選択肢: S/A/B/C/未評価）
├── コメント（複数行テキスト）
├── 商談状況（選択肢）
└── 写真（添付ファイル）

作成者・日時は自動記録
```

**ルックアップ設定:**
- ソース: 企業マスタ
- 表示列: 企業名
- 追加列: ブース番号, 事前優先度 ✓

### Phase 3: データ投入（10分）

1. `Lists用データ変換ツール.html` をブラウザで開く
2. 「データ読み込み」ボタン
3. 「CSV エクスポート」ボタン
4. Lists で「統合」→「Excel から」
5. ダウンロードしたCSVを選択
6. インポート実行

### Phase 4: テスト（5分）

1. スマホで Teams アプリを開く
2. サンプル訪問記録を追加
3. 複数人で同時編集テスト

## 💡 重要なポイント

### ✅ できること

| 機能 | 詳細 |
|------|------|
| 複数人同時記録 | 同じ企業に別々の記録を追加可能 |
| リアルタイム共有 | 保存と同時に全員が閲覧可能 |
| 自動記録 | 訪問者名・日時は自動 |
| 写真管理 | 各記録に複数枚添付可能 |

### ❌ 現在の制限

| 制限 | 回避策 |
|------|--------|
| 写真はExcelエクスポートに含まれない | SharePointから手動ダウンロード<br>または Power Automate で自動バックアップ |
| 完全オフライン不可 | 展示会場のWi-Fi利用を推奨 |
| 未訪問企業の自動抽出不可 | ビューで手動フィルター<br>または Power Automate で集計 |
