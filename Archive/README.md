# 過去版の保管

イベント別の旧版・検討時のスナップショットを保管します。終了したイベントの現行ページも日付付きフォルダに残るため、開催日が過去という理由だけでここへ移しません。

- 現行の公開入口は [ルートの案内](../index.html) から確認します
- 同名イベントのフォルダがルートにもある場合、ここは旧版、ルート側は公開用です
- 内容の取り込み状況はファイルごとに確認します。旧版だから不要・再利用可能とは判断しません
- 個人書類などGitの対象外のファイルは、このREADMEの追加によって追跡・公開しません

新しいイベント内の参考資料は次の分類を使います。既存のURLを保つため、この保管庫は移動しません。

| 分類 | 用途 |
|---|---|
| `references/design-samples/` | 採用案を含むデザイン比較 |
| `references/rejected/` | 却下した試作 |
| `references/superseded/` | 現行仕様・旅程に置き換えられた旧案 |
